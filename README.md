## 📄 Description
The Python-Calculator is a basic calculator implemented in Python, designed to perform arithmetic operations. It is intended for users who need a simple and lightweight calculator. The key benefit of this project is its ease of use and minimal dependencies.

> 🎯 **Key Highlights**
> - ⚡ Fast and lightweight
> - 📊 Simple arithmetic operations

## 🎨 Features
| | Feature | Description |
|:--:|---------|-------------|
| 📝 | **Basic Arithmetic** | Addition, subtraction, multiplication, division |

### Prerequisites

### Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/username/Python-Calculator.git
   cd Python-Calculator
   ```

2. **Run the calculator**
   ```bash
   python calculator.py
   ```

### Environment Variables
No environment variables are required.
